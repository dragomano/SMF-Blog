Обзор старейшего популярного портала для SMF, для нетребовательных пользователей.

<!-- more -->

EzPortal добавляет к форуму собственную главную страницу, собственный менеджер страниц, колоночную сетку и библиотеку блоков (ezBlocks) — от «последних тем» и статистики до встроенных RSS-лент, галерей и виджетов сторонних модов.

Поверх форума EzPortal формирует полноценную портальную структуру: собственный домашний адрес, редактируемые страницы, произвольное число колонок и десятки готовых блоков, которые собираются в портал как конструктор.

{{ img('Пример главной страницы портала', 'ezportal_preview1.png') }}

## Особенности

* Очень шустрый.
* Поддержка страниц и блоков в разных форматах.
* Пять стандартных панелей для размещения блоков.
* Поддержка прав доступа для настройки портала, управления страницами и блоками.
* Возможность создания собственных блоков.
* Создаваемые страницы можно размещать в главном меню.
* Генерация ЧПУ-адресов страниц.

## Разделы админ-панели

В панели администратора форума появляется отдельный раздел **EzPortal** с тремя вкладками.

| Вкладка | Назначение |
|---|---|
| **Настройки EzPortal** | Общая конфигурация портала, управление модулями, импорт данных из других систем порталов |
| **Менеджер страниц EzPortal** | Создание, редактирование и удаление страниц портала через удобный интерфейс |
| **Менеджер блоков EzPortal** | Создание и управление блоками, колонками и порядком их размещения |

Каждая вкладка имеет собственное описание в админке, чтобы можно было быстро сориентироваться, куда идти.

## Страницы портала

### Создание и типы страниц

Менеджер страниц поддерживает четыре сценария работы:

- **Добавить страницу** — пустая страница с редактором.
- **Добавить страницу с BBC** — страница, наполняемая через BBC-код.
- **Добавить страницу Markdown** — текст в формате Markdown, отрисовывается через Parsedown.
- **Изменить страницу / Удалить страницу** — редактирование и удаление с подтверждением.

Каждая страница определяется заголовком и содержимым, а тип контента выбирается из трёх вариантов:

| Тип страницы | Описание |
|---|---|
| **HTML** | Произвольный HTML-код |
| **BBC** | Форматирование средствами BBC-редактора форума |
| **Markdown** | Заголовки, списки, ссылки, изображения, код и таблицы через Parsedown |

Для страниц Markdown доступна опция **«Разрешить сырой HTML внутри страниц Markdown»** — она помечена как небезопасная и рекомендуется только при полностью доверенных менеджерах страниц.

Справка по синтаксису: `# Заголовок`, `**полужирный**`, `*курсив*`, `[текст](https://ссылка)`, `![alt](url)`, `- пункт списка`, `1. нумерованный пункт`, `> цитата`, `` `код` ``, блок кода в тройных кавычках, `| таблица | колонки |`. Между абзацами оставляется пустая строка.

### Колонки

Страницы и блоки размещаются в колонках, которыми управляет менеджер блоков:

- **Добавить столбец / Изменить столбец / Удалить столбец** — полный цикл работы со столбцами.
- **Ширина столбца** — задаётся в пикселях либо в процентах. Указание процентов переопределяет абсолютную ширину; значение должно быть больше нуля.
- **Заголовок столбца** — подпись над колонкой.
- **Сворачивание столбца** — колонка целиком можно свернуть.
- **Закрепить столбец** — столбец остаётся видимым при прокрутке вниз.
- **Порядок** — позиция колонки относительно других.

### Правила отображения

Видимость страниц и блоков задаётся независимо от прав доступа — это «Области отображения».

| Настройка | Смысл |
|---|---|
| Области | Действия форума, в которых элемент показывается |
| Зависимость от других модов | Элемент работает, если установлена соответствующая модификация |
| Разделы | Привязка к конкретным разделам форума |
| Страницы | Привязка к конкретным страницам портала |
| Все области и разделы | Показывать везде без ограничений |
| Главная страница портала | Только на главной странице |
| Форум | Только на страницах форума |
| Главная страница форума | Только на индексе форума |

Новые области добавляются вручную: указывается заголовок области и сама область. Обратите внимание на формат — вводится только часть после `action=actionhere`. Типичные примеры: `profile`, `gallery`, `search`.

Ссылка с http:// в правиле видимости не поддерживается — используются только внутренние действия форума (`gallery`, `shop`, `arcade` и т. п.).

## Блоки (ezBlocks)

### Управление блоками

| Действие | Описание |
|---|---|
| Добавить блок | Создание нового блока с выбором типа, заголовка и содержимого |
| Изменить блок | Редактирование любых свойств блока |
| Удалить блок | Удаление с подтверждением |
| Сохранить блоки | Фиксация изменений сразу по всем блокам |
| Загрузка блоков | Установка готовых блоков из файла `block-info.xml` |
| Установленные блоки | Список уже установленных блоков |

Свойства блока: **тип**, **заголовок**, **версия**, **автор**, **контент**, **столбец**, **менеджеры блоков**, **дополнительные настройки**, **разрешение сворачивания**.

### Источники блоков

У каждого блока указывается источник, и это важно при диагностике:

| Источник | Значение |
|---|---|
| **EzPortal** | Блок входит в поставку ядра |
| **Модификация** | Блок регистрируется через хук установленной модификации |
| **Загружен** | Блок загружен пользователем в виде `block-info.xml` |

### Типы ezBlock

Страница **«Создать ezBlock»** генерирует готовые заготовки файлов для нового блока:

| Тип | Описание |
|---|---|
| PHP-функция, регистрируемая модификацией | Рекомендуемый способ: модификация отдаёт callback-функцию |
| `block-info.xml` с PHP-кодом | Файл с PHP-кодом, загружается на странице «Загрузка блоков» |
| `block-info.xml` с HTML-кодом | Файл с HTML-кодом, загружается на странице «Загрузка блоков» |

При создании заготовки задаются: заголовок блока, идентификатор (вендор:имя, допустимы буквы, цифры, `_`, `:`, `.`, `-`), автор, сайт и тип. Документация для разработчиков поставляется вместе с EzPortal в папке `docs` — начать стоит с `docs/block-development.md`. Готовые наработки принято публиковать на ezportal.com.

### Типы параметров

Параметры блока могут храниться в разных форматах: параметры, сохраняемые как есть, и параметры, которые PHP-функция блока получает готовыми к использованию.

### Эксплуатация и диагностика

- **Перезагрузить определения блоков** — перечитывает определения из EzPortal и установленных модов, переносит старые значения параметров и очищает весь кэш блоков. Нужно после установки или обновления мода с ezBlocks.
- **Экспорт** — скачивает блок в виде `block-info.xml`, который затем загружается на другой форум.
- **Отладочный режим блоков** — под каждым ezBlock показывает время отрисовки, статус кэша и функцию обратной связи. Видно только администраторам.
- **Источник / Ключ / Параметры** — техническая информация о конкретном экземпляре блока.

Типовые ошибки блоков различаются точно: **нет определения** для типа блока, **требуется неустановленная модификация**, **не удалось отобразить** (исключение), **функция обратной связи не существует** (мод больше не установлен), **неизвестный ezBlock**, **нет доступа** к блоку, **у блока нет обработчика AJAX**. Отдельно предупреждается, что база EzPortal ещё не обновлена — в этом случае нужно повторно запустить обновление пакета EzPortal (`EzPortalInstall2.php`).

## Мини-чат (shoutbox)

Мини-чат — встроенный AJAX-блок с собственной панелью настроек.

| Параметр | Описание |
|---|---|
| Включить мини-чат | Общий переключатель |
| Время задержки между сообщениями | Интервал между отправкой сообщений |
| Время обновления окна мини-чата в секундах | Автообновление; значение 0 отключает обновление |
| Показывать дату в чате | Отображение временной метки |
| Показывать ссылку на историю чата | Ссылка на полную историю |
| Количество элементов на одной странице в истории чата | Пагинация истории |
| Показывать иконки для вставки ББ-тегов в чате | Панель BBC-кнопок |
| Показывать смайлики в чате | Панель смайликов |
| Скрыть слово «написал(а)» в чате | Убирает служебное слово перед ником |
| Скрыть кнопку для удаления записей | Убирает кнопку удаления из чата |
| Удалить всю историю чата | Полная очистка истории без возможности восстановления |

Мини-чат умеет запрещать гостям публиковать сообщения, проверяет задержку между отправкой (в том числе по IP-адресу), требует непустой текст сообщения и уважает бан на публикацию сообщений на уровне форума.

## Менеджер меню

Отдельный блок функциональности для построения навигации:

- **Добавить пункт меню / Изменить пункт меню / Удалить пункт меню**
- Заголовок пункта — обязателен, ссылка — обязательна.
- **Открывать в новом окне** — дополнительная опция для пункта.
- **Порядок** — сортировка пунктов вверх и вниз.
- **Включено** — активность пункта.

Важная деталь: сначала создаётся сам блок меню, а уже затем — пункты меню для него.

### Импорт из TinyPortal

Импортируются **страницы, блоки и сообщения чата** из другого портала, установленного в той же базе данных форума. Исходные таблицы только читаются и никогда не изменяются. Поддерживается TinyPortal от 1.x до 3.x.

Что происходит при импорте:

- Статьи BBC и HTML становятся **страницами**; статьи PHP пропускаются.
- Блоки становятся **ezBlocks**, SSI-блоки превращаются в PHP-ezBlock с вызовом функции из `SSI.php`.
- Пункты меню и сообщения чата переносятся отдельно.
- Позиции блоков, права доступа и правила отображения сопоставляются там, где в EzPortal есть аналог; несопоставленное перечисляется после импорта.
- Повторный запуск добавляет только те элементы, которые не импортированы ранее.
- Есть действие **«Удалить импортированные элементы»** — снимает созданные страницы и блоки, чтобы импорт можно было запустить с нуля. Сообщения чата при этом сохраняются.

Отдельные предупреждения информируют о нюансах: PHP-код копируется как есть, но функции TinyPortal и значения `$context['TPortal']` в EzPortal отсутствуют; TinyPortal умел ограничивать блок списком разделов, а EzPortal умеет только исключать разделы, поэтому блок теперь показывает темы из всех разделов; правила отображения без аналога отбрасываются, и если не сопоставлено ни одно правило, блок показывается везде.

Блоки без аналога в EzPortal (статистика статей и загрузок, карта сайта, административные блоки, категории статей, рекомендуемые темы, блоки с одной статьёй) корректно помечаются как пропущенные, а не переносятся.

## Права доступа

Создаётся отдельная группа прав **EzPortal** с подгруппами.

| Право | Описание |
|---|---|
| **Использование EzPortal** | Базовый доступ к порталу |
| **Управление страницами** | Добавление, редактирование и удаление страниц |
| **Управление блоками** | Добавление, редактирование и удаление блоков |
| **Настройка EzPortal** | Полный контроль над порталом |

## Технические заметки

| Требование | Зачем |
|---|---|
| Папка `ezcache` должна быть доступна для записи | Используется для кэша блоков. При недоступной записи EzPortal предупреждает о снижении производительности |
| Поддержка `mod_rewrite` | Нужна только для ЧПУ-адресов страниц |
| Модификация Responsive Curve | Нужна для адаптивного режима портала |
| `Sources/Parsedown.php` | Нужен для ezBlock Markdown и страниц Markdown; поставляется в пакете EzPortal |
| Обновление базы данных EzPortal | Перед добавлением или изменением ezBlocks нужно повторно запустить обновление пакета |

Добавляет кнопку «Новое обсуждение» в стиле XenForo над списком разделов на главной странице форума.

<!-- more -->

{{ img('Вид кнопки на главной странице форума', 'new_discussion_button.png') }}

{{ settings('Конфигурация → Настройки модификаций.') }}

## Особенности

- При нажатии открывается список разделов, в которых текущий пользователь может создать новую тему; после выбора нужного раздела открывается страница создания новой темы для него.
- В списке отображаются только разделы, в которых действительно можно создать тему, поэтому участники не столкнутся с сообщением «У вас нет прав для выполнения этого действия».
- Текст кнопки можно изменить в настройках.

??? Русификация

    Добавить в файл `Themes/default/languages/NewDiscussionButton.russian.php`:

    ```php
    <?php

    // Строки интерфейса.
    $txt['newdiscussion_button'] = 'Новое обсуждение';
    $txt['newdiscussion_choose'] = 'Выберите раздел';
    $txt['newdiscussion_filter'] = 'Фильтр разделов...';
    $txt['newdiscussion_none']   = 'Нет разделов, соответствующих фильтру.';

    // Настройки администратора (Конфигурация > Настройки модификаций).
    $txt['newdiscussion_settings_title'] = 'Кнопка «Новое обсуждение»';
    $txt['newdiscussion_enabled']        = 'Показывать кнопку «Новое обсуждение»';
    $txt['newdiscussion_label']          = 'Текст кнопки';
    $txt['newdiscussion_label_subtext']  = 'Оставьте поле пустым, чтобы использовать значение по умолчанию («Новое обсуждение»).';
    ```

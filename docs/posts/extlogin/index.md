## Особенности

- Вход на форум через Google, GitHub, VK ID, Яндекс, Facebook и Telegram (OAuth 2.0 и OpenID Connect).
- Кнопки авторизации выводятся на странице входа отдельным блоком под ссылкой «Забыли пароль?».
- Регистрация нового участника по данным профиля провайдера: имя пользователя генерируется автоматически, пароль не задаётся.
- Привязка внешнего профиля к существующему аккаунту форума — только после подтверждения владения почтовым ящиком (ссылка действует 24 часа, в базе хранится только хэш токена).
- Раздел «Внешние аккаунты» в профиле участника: список привязок, дата привязки, отвязка отдельной связки. Последнюю привязку отвязать нельзя.
- Настройка «Разрешить авторизацию при выключенной регистрации» — при желании вход через внешние сервисы продолжает работать и при закрытой регистрации.
- Поддержка штатных режимов регистрации форума: мгновенная регистрация, «По одобрению», «С активацией», «Активация + одобрение».
- Приветственное письмо с именем пользователя и ссылкой на восстановление пароля — пароль в письмо не передаётся.
- Перенос аватара из профиля провайдера в профиль участника форума.
- Поддержка PKCE (Google, VK ID, Яндекс) и проверка параметра state — защита от подделки запросов и CSRF.
- Все запросы к провайдерам выполняются по HTTPS с обязательной проверкой сертификатов.
- Пользовательские сообщения мода (подтверждение привязки, ожидание активации, ошибки) выводятся обычными страницами со статусом 200 — «дружественные» страницы ошибок хостинга их не подменяют.
- Ошибки входа пишутся в журнал SMF без утечки секретов.
- Совместимость с MySQL, MariaDB и PostgreSQL.
- Мод построен только на хуках: установка через менеджер пакетов, правка файлов форума не требуется.
- Русский и английский языки интерфейса.

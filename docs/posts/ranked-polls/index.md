Добавляем в SMF рейтинговые голосования с использованием системы мгновенного второго тура.

<!-- more -->

Вместо выбора одного ответа участники упорядочивают варианты опроса по степени предпочтения. Если ни один вариант не набирает большинства голосов продолжающих голосование, наименее популярный кандидат исключается, а его голоса передаются следующим доступным вариантам избирателей.

Процесс продолжается до определения победителя.

## Особенности

- Сохранение существующих опросов SMF
- Работа с помощью хуков, никаких правок файлов движка
- Выдача разрешения на создание опросов с ранжированием только определённым группам пользователей
- Возможность создавать опросы с ранжированием только в заданных разделах форума
- Возможность перетаскивать варианты опроса
- Создание анонимных бюллетеней
- Подробная отчётность по раундам
- Экспорт результатов и бюллетеней в CSV
- Оповещения о закрытии голосований и удаление данных об удалённых опросах
